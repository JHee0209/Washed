## 토큰이 파일로 없는 이유

이 프로젝트의 화면은 `tokens.css` 같은 토큰 파일 없이 **인라인 hex 값으로 그려져 있다.**
따라서 색 · 크기를 바꿀 때는 세 곳을 함께 고친다 —
`docs/07-screens.md` 「디자인」 · `src/app/globals.css` · 해당 `.dc.html`.

`Design System.dc.html` 은 토큰 참조표와 공통 컴포넌트(버튼 · 입력칸 · 상태 배지 · 기기 카드 ·
대기열 · 타이머 · 모달 · 토스트 · 내비게이션)를 한 화면에 모아 놓은 것이다. 브라우저로 열어서 본다.

## 함께 있어야 도는 파일

화면끼리 상대경로로 서로를 부르므로 **이 폴더 구조 그대로** 두어야 열린다.

| 파일 | 쓰임 |
|---|---|
| `support.js` | 모든 `.dc.html` 이 `<head>` 에서 부른다 |
| `i18n.js` | 네 언어 사전 · 국기(`FLAGS`). 한국어 원문이 키다 |
| `i18n-docs.js` | 약관 · 개인정보 동의서 본문 번역 (회원가입) |
| `ios-frame.jsx` | 화면을 감싸는 폰 테두리 (`x-import` 로 부른다) |
| `image-slot.js` | 설정 화면의 신고 증거 사진 칸 |
| `icons/` | 기기 상태 아이콘 · 종 · 국기 · 로고. 경로가 `icons/…` 라 폴더명을 바꾸면 깨진다 |
| `github.md` | `Design System.dc.html` 의 토큰 · 컴포넌트가 어느 오픈소스(Montage · Wanted Lab · MIT)의 어느 파일에서 왔는지 적은 출처 표다. 화면이 부르지는 않는다 |

캔버스 작업 부산물(`uploads/` · `screenshots/` · 낱장 아이콘 시안 `bell-48-*.svg` 등)은 여기로 옮기지 않는다 — 화면이 부르는 파일과 `icons/` 만 둔다.

## 클로드 디자인에 아직 반영하지 않은 로컬 수정

여기 파일은 클로드 디자인에서 **내려받은 사본**이다. 아래는 문서 확정에 맞춰 **이 폴더에서 먼저 고친 것**이라,
클로드 디자인 프로젝트에서도 같게 고치지 않으면 **다음에 내려받을 때 되돌아간다.**

| 파일 | 무엇을 고쳤나 | 확정 근거 |
|---|---|---|
| `알림.dc.html` | `notExpiredEarly` 필터를 `offset < 30` 에서 `offset < KEEP_DAYS(n.type)` 으로 바꿨다 — 「공지」만 90일, 나머지 네 종류는 30일 | 공지 항목은 3개월 보관이라 30일로 자르면 살아 있는 공지를 사생만 못 본다 · 05 P14 · P18 |
| `관리자.dc.html` | 경고 탭 월 목록을 `for (let i = 0; i < 12; i++)` → `i < 3` 으로 줄이고, 목록 밖의 달을 뒤에 덧붙이던 `warningDefs.forEach(...)` 한 줄을 지웠다 | 경고 기록은 3개월만 보관하므로(05 SP4) 넉 달 전 달을 고르면 늘 빈 목록이었다 · 04 F25 · 05 P7 · 07 |
| `관리자.dc.html` | `reportDefs` → `reportDefsAll` 로 바꾸고 `reportCutoff`(3개월)로 거른 것을 `reportDefs` 로 뒀다 · `warnLogAll` 에도 `warnLogCutoff`(3개월)를 걸었다 | 신고 · 증거 사진 · 경고 기록 모두 3개월 보관인데 이 둘만 컷오프가 없었다 · 05 P23 · SP4 |
| `기록.dc.html` | `washed_warnlog` 를 사용자 키로만 거르던 것에 `warnCutoff`(30일)를 더했다 | 화면은 "최근 30일" 이라 적어 놓고 3개월치 사유를 다 보여주고 있었다 · 05 P21 |

반영한 뒤에는 이 절에서 해당 줄을 지운다.

## 문구를 고칠 때

번역은 **한국어 원문을 키로** 쓴다. 사전에 없는 문장은 조용히 한국어로 남는다(05 P25).
화면 문구를 새로 쓰거나 고치면 `i18n.js`(약관은 `i18n-docs.js`)의 네 언어를 함께 본다.
