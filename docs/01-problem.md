## 4요소

| 칸 | 내용 |
|---|---|
| **문제** | 동아리(12명) 총무가 모임 일정을 단톡방에 올리면 **공지가 대화에 묻혀** 매번 **3~4명이 날짜 · 장소를 다시 묻는다** |
| **대상** | 매주 모임을 여는 **대학 동아리 총무** (구성원 10~15명) |
| **현재해법** | 단톡방 공지 + 공지 고정 + 각자 폰 캘린더에 옮겨 적기 |
| **불편** | 참석 여부가 대화 속에 흩어져 있어 총무가 **모임 전날 30분** 동안 세고 다시 묻는다. 일정이 바뀌면 **옛 공지를 본 사람이 잘못 온다** (30분 · 3~4명은 짐작 — 물어볼 것) |

## 한 문단으로

매주 모임을 여는 대학 동아리 총무는 단톡방 공지와 고정 메시지로 일정을 알리는데, 공지가 대화에 묻혀 매번 서너 명이 다시 묻고, 참석 여부가 흩어져 있어 전날 30분을 세는 데 쓰며, 일정이 바뀌면 옛 공지를 본 사람이 잘못 온다.

## 유사 서비스 3개 (팀 Project 조사 · 직접 접속해 확인)

| 서비스 | 우리 4요소 중 푸는 것 | 못 푸는 것 | 확인한 사람 |

| 구글 캘린더 공유 | 같은 일정표를 모두가 본다 · 초대 응답 | 동아리원 전원이 구글 계정 · 앱을 써야 한다 — 단톡방 밖으로 나가야 한다 | 민수 |
| 네이버 밴드 | 모임 일정 · 참석 투표 · 게시 | 일정 하나 보려고 게시글 · 사진 · 채팅이 함께 있는 앱을 하나 더 깐다 | 서연 |

## 확인할 수 없어 표시해 둔 것

- "모임 전날 30분" — 짐작이다. 인터뷰에서 물어본다
- "3~4명이 다시 묻는다" — 팀원 한 명의 동아리 단톡방을 센 값. 다른 동아리도 그런지 물어본다
