# 화면 — 팀 일정 관리

> 문서: 07-screens.md · 상태: 초안 · 열린 질문 [?] 0개 · 채택한 [제안] 1개 · 마지막 갱신: 수
> 이 문서를 읽는 에이전트에게: 여기 없는 것은 지어내지 말고 질문으로 돌려라. 화면 목록에 없는 화면 · 흐름표에 없는 이동을 만들지 않는다. 주소(URL)는 여기 없다 — 만드는 쪽이 제안하고 팀이 확정한다.

> ⚠️ 강사 예시입니다. 화면 3 ≤ MVP 기능 5. 추가와 수정은 한 화면(일정 입력)으로 합쳤다 — 이 결정이 여기 적혀 있어야 다음에 에이전트가 둘로 쪼개지 않는다.

## 모든 화면 공통 인수 조건
- 모든 화면은 폰 세로(390px)에서 가로 스크롤 없이 보인다 — PC 는 부품의 "PC 에서는" 줄대로.
- 저장이 걸린 동작은 다른 기기 · 다른 사람이 새로고침해도 같은 것이 보인다(3중 확인 — 새로고침 · 다른 기기 · 다른 사람 · 모든 저장에).
