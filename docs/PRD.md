# PRD — 팀 일정 관리

> 문서: PRD.md · 상태: 완성본 · 열린 질문 [?] 1개 · 마지막 갱신: 금
> 이 문서를 읽는 에이전트에게: 이 문서는 02~07 을 **번호로 가리키는** 최종 문서다. 문장은 가리킨 문서에 한 번만 있다 — 여기 없는 것은 지어내지 말고 질문으로 돌려라. 「안 만드는 것」에 있는 것은 만들지 않는다.

> ⚠️ 강사 예시입니다. 1절은 수요일(요구사항 확정)에 팀이 종합·병합해 확정한 것 — 사람은 번호가 02~05에 있는지만 확인했다. 2~5절은 목요일까지 나온 06·07을 번호·링크로 가리킨 것이고, 6절은 오늘(금) 아침 읽기 테스트 전 상태를 담았다.
