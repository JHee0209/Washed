## 0. 한 문단

기숙사 세탁실을 쓰는 사생은 빈 기계가 있는지 알려면 직접 내려가 보는 수밖에 없어 헛걸음을 하고, 남은 시간을 몰라 몇 번씩 다시 내려가며, 여러 명이 동시에 기다릴 때 순서를 정하는 기준이 없어 먼저 넣는 사람이 임자가 된다. (`docs/01-problem.md`)

## 6. 열린 질문 갱신

- 프로토타입은 브라우저 `localStorage` 로 화면끼리 데이터를 주고받는다. 실제 사용자가 여럿이 되면 **같은 기기에 두 명이 배정될 수 있고**, 앱을 켜지 않은 사람에게는 경고가 기록되지 않는다. 고쳐야 할 자리는 `docs/08-deployNOTE.md` 에 파일 · 식별자 단위로 적어 두었다.
- 관리자 비밀번호와 인증코드가 클라이언트 코드에 문자열로 있다 — 배포 전에 반드시 서버로 옮긴다(08 · 1번).
- 보관 · 삭제 규칙이 확정됐다 — 탈퇴는 **14일 유예 후 삭제**(05 P24)이며, 이용 내역 · 경고 · 신고(증거 사진 포함)는 3개월 또는 탈퇴 후 14일 중 먼저 오는 때에 삭제한다(05 SP4 · P23). 회원가입 약관 본문과 설정의 탈퇴 모달도 같은 문장으로 고쳤다.
- 나머지는 1절 「열린 질문」과 같다.
